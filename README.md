# Character Selection

A lightweight Unity UI package that provides a customizable character selection / character list interface with buttons, animated windows, countdown bars, and gradient UI effects. Designed as a drop-in UI module for Unity projects (uses Unity UI + TextMeshPro)

---

## Features
- Character selection UI with preview icons, descriptions and abilities.
- Button animations and sound hooks for hover / click / select.
- Window/tab manager for switching panels.
- Countdown progress bar with events.
- UI gradient mesh effect for styled text/images.
- Fully customizable via Inspector (no code changes required).
